Instalar en 10 segundos

  1. Descarga el DMG clicando arriba (o desde Releases)
  2. Abre el DMG y arrastra MAKP.app a Aplicaciones
  3. Primer arranque: clic derecho → Abrir (firma ad-hoc, no notarizado aún) → Permitir

Requisitos

  • macOS 26.5 Tahoe o superior
  • Apple Silicon (arm64) y Intel (x86_64) — build universal si usas scripts/create-dmg.sh con --universal
  • Sin sandbox, acceso completo a discos externos

¿Quieres distribuir sin “Unidentified developer”? Firma con tu DEVELOPMENT_TEAM y notariza con notarytool. Ver scripts/create-dmg.sh en el repo privado.

Generar tu propio DMG (repo privado)
# 1. Clona (requiere acceso al repo privado)
git clone https://github.com/andyechc/makp.git
cd makp

# 2. Build + DMG (Release)
chmod +x scripts/create-dmg.sh
./scripts/create-dmg.sh

# DMG resultante: dist/MAKP-1.1.dmg

# 3. Publicar en esta landing (repo público):
gh release create v1.1 dist/MAKP-1.1.dmg \
  --repo andyechc/makp-landing \
  --title "MAKP v1.1" --notes "Primera release pública"

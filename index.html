Fondos con material, hover states y controles auto-hide. Inspirado en Tahoe 26.

Diseñado para ver, no para configurar

Todo lo que esperas de un gestor + reproductor nativo, sin Electron ni plugins raros.

🗂️

Navegación real

Sidebar con volúmenes APFS/ExFAT, breadcrumbs, lista y grid, búsqueda ⌘F instantánea y flechas.

👁️

Hover preview

Thumbnails al pasar, duración y metadata sin abrir. Cache inteligente para miles de archivos.

▶️

Motor dual

AVFoundation por defecto (HW) + VLCKit auto para MKV/AVI/WMV/WEBM.

🎞️

Playlist inteligente

Resume modal, “continuar donde lo dejaste”, sidebar de playlist y selector de audio/subs.

✨

Liquid Glass

Toolbars con material, blur 20px, saturación y estados hover de macOS 26.

⌨️

Atajos que importan

Play/pause, seek ±10s, volumen, fullscreen, next/prev — todo desde teclado.

Instalar en 10 segundos

  1. 1Descarga el DMG clicando arriba o desde Releases
  2. 2Abre el DMG y arrastra MAKP.app a Aplicaciones
  3. 3Primer arranque: clic derecho → Abrir (firma ad-hoc, no notarizado) → Permitir

Requisitos

  • macOS 26.5 Tahoe o superior
  • Apple Silicon & Intel — universal con --universal
  • Sin sandbox, acceso completo a discos externos

Para evitar “Unidentified developer” firma con tu DEVELOPMENT_TEAM y notariza con notarytool. Workflow listo en scripts/create-dmg.sh.

Terminal — zsh copiar 
# 1. Clona (requiere acceso al repo privado)
git clone https://github.com/andyechc/makp.git
cd makp

# 2. Build + DMG (Release)
chmod +x scripts/create-dmg.sh
./scripts/create-dmg.sh

# DMG resultante: dist/MAKP-1.1.dmg

# 3. Publicar en esta landing (repo público):
gh release create v1.1 dist/MAKP-1.1.dmg \
  --repo andyechc/makp-landing \
  --title "MAKP v1.1" --notes "Primera release pública"
